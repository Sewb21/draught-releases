# Draught beta downloads

Draught is a fast Git client with a review workspace for AI-written code,
available for macOS, Windows and Linux.

**[Download a published beta](https://github.com/Sewb21/draught-releases/releases)**

This repository hosts installers, release notes and public feedback. The
application source is private.

## Beta licence

Draught is proprietary software. Official beta builds are free for personal
and commercial use under the `LICENSE.txt` attached to each release. Existing
beta builds remain free to use; future releases may require a paid licence.
Third-party components retain their own licences.

## Feedback

[Open an issue](https://github.com/Sewb21/draught-releases/issues) for bugs,
questions or feature ideas. Include your Draught version, operating system,
steps to reproduce and what you expected to happen. Remove private code,
repository paths, credentials and other sensitive data before attaching logs
or screenshots.

## Installation

- macOS: download the DMG for Apple Silicon (`aarch64`) or Intel (`x64`).
  Official releases are signed and notarised. Requires macOS 12 or later.
- Windows: use the x64 EXE or MSI installer. Windows signing is not configured
  yet, so SmartScreen may show a warning.
- Linux: choose the x64 AppImage, DEB or RPM for your distribution.

Git is required. AI features are optional and use your own provider account.
Each release includes platform-specific SHA-256 checksum files.

GitHub's automatic source ZIP/tar downloads contain this repository's
documentation, not the Draught application source.
